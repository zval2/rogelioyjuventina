## Publicar con GitHub Pages

1. Reemplaza los archivos de tu carpeta local con estos archivos.
2. Prueba `index.html`.
3. En GitHub Desktop, haz **Commit to main**.
4. Haz **Push origin**.
5. En GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
